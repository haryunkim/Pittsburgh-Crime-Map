# Pittsburgh Crime Map

Currently in progress.

You can view the site here: https://haryunkim.github.io/Pittsburgh-Crime-Map/

## Data
The Data is provided by the Western Pennsylvania Regional Data Center's Monthly Criminal Activity Dataset (https://data.wprdc.org/dataset/monthly-criminal-activity-dashboard). The most recent update is from March 2026.

## Tools
Data preprocessing is done using Python. The frontend uses React, Vite, and Leaflet.
